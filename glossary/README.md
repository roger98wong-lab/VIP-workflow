# 术语主库

`master.csv` 是按【游戏】隔离、黄标确认后写入的锁定译名。`game` 必须与 `games.md` 的「游戏」列一致。其他游戏即使中文词相同，也不得采用。

各游戏的完整语言表在 `glossary/<目录名>/lang/`，往期在 `glossary/<目录名>/past/`。

出稿顺序：先写中文成稿，再从成稿抽词。查词顺序：

1. 该游戏语言表（道具名以此为准）
2. 本期 `inbox/glossary/`
3. `master.csv` 中当前游戏的行
4. 都没有：先翻译并黄标，禁止近义自译

新增词流程：本期黄标确认 → 追加一行（含游戏）→ 提交 git。

`locked=yes` 的行禁止模型改写。
