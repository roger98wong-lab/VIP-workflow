- 语言表：`glossary/zzsj/lang/2026-09-30/y语言表.xlsx`（data 表，B 列中文 → E–K 列译文）。禁止拿冒险大作战的词来凑

## 共用

- 对外品牌：永远写 **Legend of Element**。中文稿标题里也不改成「主宰世界」。
- 玩家称呼：冒险者（Adventurer）。玩法稿里出现「修士」时按玩法原文，不要改成菇勇者。
- 官网链接（DC 用裸链；短公告/VIP 可用官网入口句）：`https://payment.joynetgame.com/@loe?utm_pay=kf`
- 禁止把 LOM 的链接 `@lom`、称呼「菇勇者」、品牌 Legend of Mushroom 写进来。
- 必须出现的信息顺序：活动名 → 时间 → 开场一句 → 新内容/亮点（按实际类型列）→ 玩法块（有则写）→ 招财猫（有则写）→ 官网充值
- 道具类型按成稿实际写，不要套 LOM 的「神器/坐骑/背饰」三件套。往期常见：神器、法宝、坐骑、仙友、法则、时装、武器、秘宝、法相、飞剑、领域、仙器、神兵。
- 道具名标记：中文用【名字】或「名字」；类型在前，例如 `神器【浴火神弓】`、`法则-【自然领域】`
- 神器 / 坐骑 / 法宝 / 仙友等技能：只写介绍效果或一句意象，不写数值，不照搬策划效果原文。往期本身就是意象句（如「刀斩轮回，镜映宇宙」），沿用这个密度。
- 时间：中文 `2026年7月17日-2026年7月23日` 或短写 `6月1日-6月7日`（用 `-`，与 LOM 的 — 不同）
- 常驻块「招财猫」：有本期再写。累计充值领喵喵钥匙，最多 8 次，开箱有机会出玄钻。钥匙名以成稿为准（喵喵钥匙 / 喵喵销匙 往期混用，出稿统一「喵喵钥匙」，黄标即可）。
- 返场写「回归」或「限时返场」+ 类型 + 名，不要硬改成 LOM 的【返场神器】标题。
- 术语：中文成稿写完再抽词，用语言表查官方译。
- **US主宰语种（硬规则）：只出 cn, en, de, fr, ru, es, pt, tr。不出 ar / it。**
  Discord / VK / VIP / Excel 都不写这两语；不要生成 `ar.txt` / `it.txt`，Excel 的 ar、it 列留空。这不是缺稿，不要为此标黄。

## Discord（可含富文本）

对应往期更长、带 emoji 的那一列。只出 US主宰语种（无 ar/it）。

- 标题可包 `***`，并带主题 emoji。普通活动：`***🔥 全新活动「{活动名}」火热开启！{开场}***`；版本：`***🌿 全新版本「{版本名}」即将开启！***`；联动：`🎉✨ Legend of Element x《{IP}》联动活动开启！`
- 用【活动亮点】起头，下一行活动时间
- 新道具逐条：emoji 或 `-` + 类型 + 【名】，下一行一句介绍效果（无数值）
- 玩法块用【玩法名】小标题，只写怎么参加、能拿到什么，不要把规则长文整段搬进预热稿（九霄法会那种细则除非 notes 要求）
- 招财猫块标题常用 `🐱【喵喵喵~招财猫来到！】` 或 `【招财猫】`
- 收尾：
  ```
  ❤️【官网充值】
  通过官网充值，安全又省心，{主题收尾}：
  https://payment.joynetgame.com/@loe?utm_pay=kf
  ```
  可再加：更多活动详情，请持续关注 Discord 社区最新消息。
- 富文本：`***`、emoji、【】、「」、`-` 列表。不要 HTML，不要 `<a href='6,3,...'>`（那是短公告/VIP 的写法）
- 不要写 LOM 的 Starlight / 菇勇者 / @lom

## VK（纯文本）

往期表**没有独立 VK 行**。

- 没要求：仍出一版纯文本（Discord 去 `***`、去 HTML），语种同 US主宰（无 ar/it）；黄标写「往期无独立 VK，按 Discord 去标记」
- notes 写明本期不写 VK：则空着并黄标
- 禁止残留 `*`、`**`、`***`、HTML
- 链接只放裸 URL
- 信息与 Discord 同源，不另编卖点

## VIP后台（短文案）

对应往期短公告列。只出 US主宰语种（无 ar/it）。简短，去大段抒情。

- 标题：`【{活动名}活动开启公告】` 或 `==新版本来袭！【{版本名}】活动开启==`
- 活动时间一行
- 新道具做成清单：类型「名字」，不写长介绍；一句意象可留可不留
- 招财猫压缩到两行：时间 + 累计充值领喵喵钥匙
- 可写：更多消息，可关注官方Discord频道
- 官网入口往期用：`<a href='6,3,https://payment.joynetgame.com/@loe?utm_pay=kf'>OfficialWebsite</a>`（短公告可带这个标签；若本期 notes 要求纯文本，则改成裸链）
- 不要 emoji 堆砌，不要 `***`
