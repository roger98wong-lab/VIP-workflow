# 活动文案线程技能

按仓库根目录的 `WORKFLOW.md` 执行。不要跳步。

## 何时使用

用户提到活动文案、多语言、Discord、VK、VIP后台、术语表、活动图、往期文案、游戏分类，或口令「按活动文案流程跑」「只更新黄标」。

## 硬规则

1. 先锁定游戏。只把 `inbox/`、`games.md`、`glossary/master.csv` 中当前游戏的行、`glossary/<目录名>/`、`inbox/notes.md`、`templates/style/<目录名>.md` 当输入。聊天补充不能覆盖已锁定术语，也不能改游戏。
2. 其他游戏的术语、往期、风格一律不用。中文词相同也不借用。
3. 先填活动卡，再写中文成稿，再从成稿提取术语并查表，最后才翻译。活动卡必须有游戏。
4. 锁定术语禁止近义改写。
5. Discord / VK / VIP后台必须同源：游戏、活动名、时间、道具、返场、入口一致。
6. Discord 可携带富文本代码；VK 和 VIP后台必须是纯文本，禁止残留 Markdown / HTML 标记。
7. 缺信息也要出稿，写入黄标。游戏未写或未登记也先出稿，但不得借用其他游戏资产。
8. 输出到 `outputs/<目录名>/<活动名>/`，文件名固定。
9. 用户确认黄标后只做补丁更新，并写回该游戏主库；新游戏补登记 `games.md`。
10. 每个活动视为独立任务，不要沿用其他活动或其他游戏的道具名。
11. 往期文案只学当前游戏的结构和语气，禁止原文照抄。
12. 神器 / 坐骑 / 背饰只写介绍效果：不写数值，不照搬策划效果原文。
13. 术语必须从写完的中文成稿里提取，提取并查表之后才能翻译。

## 口令

- 「按活动文案流程跑」：完整 8 步。
- 「只更新黄标」：根据用户拍板补丁更新产物和主库，不重写结构，不换游戏。

## 语言

默认列：cn, en, de, fr, ru, es, pt, tr, ar, it。

## 完成后在对话里给

- 当前游戏（登记名 + 目录名）
- 中文 Discord（含富文本，可复制）
- 中文 VK（纯文本，可复制）
- 中文 VIP后台（短文案，可复制）
- Excel 路径
- 本期抽出的术语表
- 黄标短清单（请用户拍板）
