# 开任务口令：跑活动文案

把素材放进 inbox 后，把下面整段发给新的 Codex 任务：

请按本仓库的活动文案 workflow 跑完整流程。

输入只使用：
- inbox/notes.md（游戏必填，须与 games.md 一致）
- inbox/art/
- inbox/glossary/
- inbox/past/（仅当前游戏）
- games.md
- glossary/master.csv（仅当前游戏的行）
- glossary/<目录名>/（该游戏语言表与往期，如有）
- templates/style/<目录名>.md（如已提炼）

要求：
1. 先锁定游戏。其他游戏的术语、往期、风格一律不用。
2. 先填活动卡，再起草中文三套文案。不要先铺术语表，不要先翻译。
3. 神器 / 坐骑 / 背饰只写介绍效果，不写数值，不照搬策划效果原文。
4. 中文写完后，从成稿提取术语，查当前游戏语言表（道具名以此为准），再翻译。
5. 同时产出 Discord（可含富文本）、VK（纯文本）、VIP后台（短文案）和 Excel 总表。
6. 不确定处先出完整稿并标黄，不要停下问。
7. 产物放到 outputs/<目录名>/<活动名>/，对话里先写游戏，再贴中文 Discord、VK、VIP、抽出的术语和黄标清单。

完成后列出缺了什么、黄标有哪些，等我拍板。
